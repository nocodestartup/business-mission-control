Separe o trabalho em quatro partes: o projeto reúne a missão, a tarefa define o resultado de agora, a pasta limita o acesso e as fontes ajudam a conferir a resposta.

Pergunta-âncora: como organizo o contexto para o Codex não trabalhar no escuro?

Projeto reúne um trabalho que continuará em outras tarefas
Tarefa mostra o que precisa ficar pronto agora
Pasta limita a área do computador usada no trabalho
Fontes trazem os fatos que serão lidos e conferidos

Modelo mental

Cada camada responde a uma pergunta diferente.

Quando essas partes se misturam, o pedido fica amplo demais. Separá-las ajuda você a perceber o que está faltando antes de executar.

01 / CONTINUIDADE

Projeto

Que trabalho vai continuar ao longo do tempo? Use um projeto quando várias tarefas dependem da mesma pasta e das mesmas fontes.

02 / RESULTADO

Tarefa

O que precisa ficar pronto nesta conversa? Dê um nome que mostre o resultado, como “Inspecionar o kit da Lume”.

03 / ACESSO

Pasta local

Onde estão os arquivos desta atividade? Escolha a menor pasta que contenha tudo de que a tarefa precisa.

04 / EVIDÊNCIA

Fonte

Que arquivo ajuda a entender ou conferir? Saber de onde ele veio e para que serve importa mais do que a quantidade.

Decisão de uso

Use uma conversa solta para um pedido curto que termina ali. Use um projeto quando o trabalho tiver várias entregas ou reutilizar a mesma pasta.

Antes de seguir, confira se cada item é realmente necessário para esta inspeção.

Regra de decisão

Um arquivo só entra se ajudar nesta tarefa.

Evite incluir arquivos só porque talvez sejam úteis. Cada item precisa ter uma função clara e estar dentro da pasta escolhida.

Ajuda

Contribui para a saída?

A fonte ajuda a entender um objetivo, uma regra, um fato ou um critério desta tarefa.

Cabe

Está dentro do limite?

O arquivo está na pasta certa, tem origem conhecida e não amplia o acesso sem necessidade.

Fica fora

Aumenta risco ou ruído?

Deixe de fora dados reais, duplicatas, capturas sem origem e arquivos que não tenham uma função clara.

Organizar o contexto é escolher o que o Codex precisa ver e explicar o motivo.
